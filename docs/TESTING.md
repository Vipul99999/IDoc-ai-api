# Testing Strategy

## Unit Tests

- Classification heuristics.
- Quality score composition.
- Recommendation rules.
- Embedding similarity.
- SDK request behavior.

## Integration Tests

- Upload to analysis flow.
- OCR output generation.
- Search result retrieval.
- Translation and formatting output creation.
- Admin usage meters.

## Production Test Suites

- OCR accuracy benchmark sets.
- Load tests for upload and search.
- Security tests for auth, tenant isolation, signed URLs, and malware scanning.
- Regression suite for document processing outputs.
