# User Manual

## Upload

Open the dashboard, choose one or more supported files, select budget and urgency, then run the pipeline.

Supported examples include PDF, JPEG, PNG, TIFF, WebP, BMP, HEIC, DOC/DOCX, ODT, RTF, XLS/XLSX, PPT/PPTX, CSV, TSV, TXT, Markdown, HTML, XML, and JSON.

## Review

Use the document panel to inspect type, language, color percentage, retention date, quality score, issues, and recommendations.

## OCR

Re-run OCR when a source file changes or a better OCR engine is connected.

## Translation

Choose a target language to generate a stored translation output.

## Formatting

Choose PDF, DOCX, or PPTX to create a layout reconstruction output.

## Search

Use the search workspace to find uploaded documents by text or semantic similarity.

## Privacy

Use the privacy panel to review sensitive-data findings and create redacted sharing copies.

## Duplicates and Comparison

Use document control to find near-duplicates and compare two documents.

## Marketplace

Load vendor options to see print providers, strengths, estimated price, and delivery time.

Use Quote to estimate paper, binding, color mode, service fees, and ETA. Use Place Order to create a local print order record.

## Brand Studio

Use Brand Studio to change the product name, short logo text, tagline, marketplace name, and support email for white-label deployments.

## Workflow

Each document receives workflow states for intake, AI analysis, privacy review, print approval, and vendor handoff.
